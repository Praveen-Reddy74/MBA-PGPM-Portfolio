# Healthcare Lakehouse Strategy — Enterprise Data Modernization

**Term:** 6 · **Subject:** BDCA — Big Data and Cloud Analytics · **Professor:** Prof. Raghu Raman (per subject workbook)
**Type:** Group project (strategy + live technical demo) · **Status:** Group Project — 7 members

## Objective
Present a strategy for migrating a traditional healthcare organization from legacy on-premises RDBMS infrastructure to a modern Databricks Lakehouse architecture.

## Approach
- Framed the industry context and the strategic case for modernization in a heavily regulated (HIPAA/GDPR), high-data-volume industry.
- Designed an end-to-end Lakehouse architecture using the Medallion (Bronze/Silver/Gold) pattern.
- Built a live Spark + Medallion architecture demonstration as part of the presentation.
- Covered strategic trade-offs, financial ROI, and a final strategic recommendation, with a prepared appendix for cross-question defense.

## Output
Two linked deliverables: a detailed speaker-notes document (full narrative script, talking points, and Q&A preparation) and a self-contained interactive HTML strategy deck (including a live-data-style demo interface).

## What this demonstrates
Combines genuine technical depth (Spark/Lakehouse architecture, a working demo interface) with strategic business framing (ROI, trade-offs, recommendation) — an unusually complete package for coursework.

## Academic context
Graded group coursework for Term 6's Big Data and Cloud Analytics course.
