# Just-In-Time (JIT) Operations Analysis

**Term:** 1 · **Subject:** OM — Operations Management · **Professor:** Prof. Ravindra Ojha (per subject workbook)
**Type:** Group project (coursework report + presentation) · **Status:** Group Project — 7 members ("Group 5")

## Objective
Analyze the Just-In-Time (JIT) operations management philosophy — its core principles, benefits, and application — including a supply-chain use case involving demand-driven procurement.

## Approach
- Explained JIT's core principles: waste reduction, continuous improvement, synchronization, quality at the source, and small batch sizes.
- Analyzed JIT's benefits: reduced inventory costs, improved quality, and increased efficiency.
- Applied JIT to a supply-chain scenario involving demand-driven procurement (sourcing triggered by actual orders rather than forecasts) and discussed inventory-turnover implications.

## Output
A written report and an accompanying presentation.

## What this demonstrates
Solid grounding in core operations-management theory (JIT) with a practical supply-chain procurement application.

## Academic context
Graded group coursework for Term 1's Operations Management course.
