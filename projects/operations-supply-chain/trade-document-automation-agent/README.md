# Trade Document Automation Agent — Compliance & Efficiency

**Term:** 7 · **Subject:** SCA — Supply Chain Analytics · **Professor:** Prof. Surya Prakash / Prof. Prasad Patil (per subject workbook)
**Type:** Group project (applied AI agent) · **Status:** Group Project — 5 members

## Objective
Build an intelligent agent that automatically validates international trade documents (commercial invoices, bills of lading, packing lists, customs declarations) to reduce manual errors, compliance risk, and clearance delays.

## Context
International trade documentation is prone to manual errors and compliance issues (missing fields, incorrect data, wrong classifications), causing delays and increased operational cost.

## Approach
A hybrid AI agent combining rule-based validation with an LLM (Mistral) for more nuanced error detection: input documents (CSV/PDF/Excel) pass through extraction & normalization, rule-based validation checks, and LLM-based AI detection; flagged errors trigger an error report and email alert, while clean documents route to a review dashboard.

## Output
A presentation deck describing the problem, supply-chain context, and the hybrid agent architecture, plus an architecture diagram (`trade-document-intelligence-architecture.png`) detailing the input → processing → validation → AI-detection → alert/dashboard pipeline.

## What this demonstrates
Applies agentic-AI design (rule-based + LLM hybrid validation) to a genuine supply-chain compliance problem — directly relevant to, and a natural bridge into, an Agentic AI portfolio.

## Academic context
Graded group coursework for Term 7's Supply Chain Analytics course.
