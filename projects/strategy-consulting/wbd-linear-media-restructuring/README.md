# Warner Bros. Discovery — Strategic Restructuring Blueprint

**Term:** 2 · **Subject:** BC — Business Communication (Term 2's "BC" code — distinct from Term 3's "BC" = Business Consulting; see academic index for this workbook naming collision) · **Type:** **Individual assignment** · **Author:** M Praveen Kumar, Section B

## Objective
Analyze Warner Bros. Discovery's (WBD) strategic position following its 2022 merger, and propose a restructuring blueprint addressing the "innovator's dilemma" between declining linear TV and capital-intensive streaming economics.

## Approach
Applied the CTS (Complex Thinking / decision-making) 7-step framework: define the problem, establish and weigh decision criteria, generate alternative solutions, evaluate alternatives, select the best alternative, and build an implementation plan — applied to WBD's merger-driven restructuring challenge.

## Output
A written case-analysis report and an accompanying strategic-analysis presentation deck.

## What this demonstrates
Structured strategic decision-making (the CTS framework) applied to a real, current corporate restructuring situation, combining industry-disruption analysis with financial stress-testing and a concrete recommendation.

Individually graded coursework for Term 2's Business Communication course.
